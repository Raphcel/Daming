Mahasiswa akan diberikan satu tugas akhir. Tugas ini dikerjakan secara berkelompok,
dengan pembagian kelompok ditentukan oleh masing-masing mahasiswa. Tugas berupa
penyelesaian kasus yang diberikan dengan mengimplementasikan teknik-teknik dalam
praproses data dan teknik-teknik data mining menggunakan perangkat lunak data mining
yang tersedia. Untuk semester Genap tahun akademik 2025/2026, teknik-teknik data
mining yang dikerjakan adalah

a. Clustering dan deteksi anomali
b. Teknik klasifikasi
c. Deep learning
d. Association rule mining
e. Teknik lanjutan dalam data mining meliputi text mining, web mining, spatial data

mining, time series data mining dan sequential pattern mining
Penilaian tugas akhir dilakukan berdasarkan hasil implementasi dan analisis pada tahapan
analisis data eksploratif, praproses dan teknik data mining. Tahapan praproses data
tersebut terdiri dari:

a. Penanganan missing value
b. Diskretisasi data
c. Transformasi data
d. Normalisasi data
e. Seleksi fitur

Topik tugas akhir yang dapat dipilih mahasiswa adalah
1. Implementasi teknik data mining untuk menunjang pertanian presisi
2. Implementasi teknik data mining untuk analisis data climate change dan perubahan
tutupan lahan
3. Analisis data Mental Health Generasi Z menggunakan teknik data mining
4. Penambangan data untuk mendukung peningkatan kualitas udara di Indonesia
